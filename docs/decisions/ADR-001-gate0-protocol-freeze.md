# ADR-001: Gate 0 — 协议冻结

> 状态：已采纳 · 日期：2026-08-16 · 决策门：Gate 0（阻塞 S1）

## 背景

开写 Parser/Linter 前，须冻结 DSL 子集、世界模型、实体目录与基本产品路径，避免实现中途返工。

## 决策

| ID | 议题 | 结论 |
|----|------|------|
| G0-01 | DSL v1.0 最小指令集 | **冻结** L3 指令总表中 MVP 打 ✓ 的 22 条；未列指令视为 `@experimental`，Linter 拒绝 |
| G0-02 | 坐标系与地图尺寸 | **冻结** L1：左下原点、1 wu = 32 px、plaza 32×24、cafe_interior 16×12 |
| G0-03 | 实体目录 | **冻结** `catalog_version: 1.0.0`（3 角色、3 道具、2 场景、4 镜头、2 区域） |
| G0-04 | 剧本人工编辑 | **允许**：AI 生成或加载示例后，用户可在文本框编辑 `.mira`，再 lint → play |
| NQ-01 | 主要用户 | **观看者为主**：填封面 → 看戏；编辑剧本是辅助路径 |
| NQ-05 | 无 AI 模式 | **必须**：可跳过 AI，直接加载 `examples/minimal-play.mira` 或粘贴剧本播放 |

## 后果

- S1 范围锁定；新增指令须走 ADR + DSL 次版本
- Web UI 须含：示例播放、剧本文本编辑区
- 开发/演示不依赖 AI 可用性
