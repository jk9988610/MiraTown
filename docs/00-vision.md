# L0 — 愿景与边界

> 版本：0.1.0 · DSL 版本：1.0 · 状态：草案

## 一句话定义

**米拉小镇（MiraTown）** 是一款网页演绎游戏：用户向 AI 提供剧本封面信息，AI 按严格 DSL 输出剧本文本；程序解析剧本后，在数学规范化的二维世界中驱动居民、道具与摄像机完成演绎。AI 担任**导演**，程序担任**舞台机械师**。

## 产品旅程

```
用户输入封面信息 → AI 生成 DSL 剧本 → Linter 校验 → 编译为执行计划(IR)
    → Runtime 演绎 → 用户观看 / 回放
```

| 阶段 | 参与者 | 产出 |
|------|--------|------|
| 创作 | 用户 + AI | 符合 `04-script-format` 的剧本文本 |
| 校验 | Parser / Linter | 错误报告或 `lint_pass` |
| 演绎 | Runtime Engine | 可回放的时间轴事件流 |
| 观看 | Web UI + Renderer | 像素画面 + 对话 UI |

## 三条铁律

1. **AI 只写剧本，不写逻辑** — AI 输出 DSL 文本；路径规划、碰撞、动画插值、镜头运动均由引擎实现。
2. **一切可检索、可校验** — 剧本有固定结构；角色、场次、指令均可索引与静态检查。
3. **空间是数学对象** — 坐标、尺寸、时间均为数值；禁止模糊空间描述进入指令行。

## 主要用户

**观看者为主**：用户填写剧本封面、观看演绎。AI 生成后的剧本文本**允许人工编辑**再播放（辅助路径）。

## 范围

### 包含（MVP）

- 严格二维坐标世界（+ 独立时间轴）
- 可检索的 DSL 剧本文本格式
- 最小实体目录：3 角色、3 道具、2 场景、4 镜头预设（`catalog_version: 1.0.0` **已冻结**）
- 最小指令集：场次、出入场、移动、对话、旁白、道具、镜头、时序（`dsl_version: 1.0` **已冻结**）
- AI 输入/输出契约 + Linter 反馈循环
- 网页端观看演绎（渲染 + 摄像机）
- **无 AI 模式**：直接加载 `examples/minimal-play.mira` 或粘贴剧本播放（开发/演示必需）

### 排除（MVP 不做）

| 排除项 | 原因 |
|--------|------|
| AI 直接调用运行时 API | 破坏导演/机械师边界 |
| AI 生成可执行代码 | 安全风险；应走 DSL |
| 自然语言混入指令行 | 无法 parse；旁白走 `@NARRATION` |
| 用户实时改写演绎逻辑 | 播放中不可改；播放前可编辑剧本文本 |
| 多人在线协作导演 | 后置 |
| 语音合成 / 口型同步 | 后置；MVP 用文字气泡 |

## MVP 验收标准

一场可验收的演绎须同时满足：

1. **输入**：用户提供 `title` + `theme` + `synopsis`（≥ 20 字）
2. **输出**：AI 生成剧本，通过 `dsl_version: 1.0` Linter
3. **规模**：≥ 2 个 `@CAST` 角色、1 个 `@SCENE`、≥ 1 次 `@CAMERA` 切换
4. **时长**：30–120 秒（`duration_estimate` 落在范围内）
5. **可播放**：Web 端完整演绎，无指令未定义错误、无越界坐标

## 版本策略

- **DSL 版本**（`dsl_version`）：语义变更时递增主版本；新增可选参数递增次版本。
- **目录版本**（`catalog_version`）：实体增删改时递增；剧本须声明所依目录版本。
- Breaking change 须附迁移说明，旧剧本由 Linter 标记 `W_DEPRECATED`。
